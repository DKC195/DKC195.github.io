## Overview

This platform sits at the center of the organization's digital operations. The work goes beyond feature delivery to include infrastructure ownership, search visibility, production reliability, and long-term maintainability.

## Responsibilities

- Design, develop, and maintain the platform using Next.js, FastAPI, and MongoDB.
- Managed production hosting, DNS, SSL certificates, and deployment flow.
- Implemented and maintained GitHub-based CI/CD workflows.
- Supported technical SEO and Google Search Console visibility work.

## Stack

- Frontend: Next.js
- Backend: FastAPI
- Data: MongoDB
- Operations: Oracle Cloud, Cloudflare, SSL, GitHub Actions

## Outcomes

This project is a strong example of end-to-end ownership, combining engineering implementation, systems maintenance, and organization-facing delivery in a single role.
