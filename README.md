# DKC195-Web

Static-export Next.js portfolio for `dhirajkc195.com.np`.

## Common Commands

```bash
pnpm install
pnpm dev
pnpm build
pnpm typecheck
pnpm new:project --title "Project Title" --slug project-slug
```

`pnpm new:project` creates:

- `content/projects/<slug>.md`
- `public/content/projects/<slug>/images/.gitkeep`

See [docs/content-schema.md](/Users/dkc195/Desktop/Extras/DKC195.github.io/docs/content-schema.md:1) for the content model and project authoring rules.
